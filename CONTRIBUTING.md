# Contributing to BYOP

You do not need to write code to contribute.

## Ways to help

- Bring a safe-to-share prompt for a workshop
- Suggest a future prompt theme
- Volunteer to facilitate a prompt hot seat
- Share a reusable prompting pattern or evaluation method
- Improve the website or its accessibility

Use the repository issue forms for prompts and workshop ideas. Open an issue before a large site change so the direction can be discussed first.

Contributions should be practical, respectful, vendor-neutral, and useful across experience levels. Product experience is welcome; disguised sales pitches are not.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
